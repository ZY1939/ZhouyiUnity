# 下半部份：卦象资料库 排版规划

> 2026-06-09 设计方案存档，待下次对话继续实现

---

## 背景

- **上半部份**：起卦面板 + 算卦面板（QiguaPanel → panels_row），约占窗口 40-50% 高度
- **下半部份**：需要显示 卦图 + 易经原文 + 倪师内容 + 古籍接口，剩余 ~50-60% 窗口高度
- **挑战**：文字量极大（卦辞、彖传数百字、6爻爻辞+象曰、倪师图解/阳宅/河洛），空间有限

## 功能需求

1. 显示 `src/data/yijing/diagram/` 中的卦图（01.jpeg ~ 64.jpeg）
2. 显示 `src/data/yijing/content/` 数据库中的：
   - 易经原文：卦辞(scripture)、彖传(tuan)、大象传(daxiang)
   - 六爻：每爻的爻辞(scripture) + 象曰(xiang)
   - xx之象课(xiang_ke)：如「六龍御天之課 / 廣大包容之象」
   - history：如「此卦高祖與呂后走在芒碭山卜得之」
   - 倪师内容：图解(diagram)、卦解(interpretation)、阳宅(home)、河洛(heluo)
3. 易经原文**始终显示**
4. 按钮切换：倪师 ↔ 古籍（可扩展更多古籍）
5. 预留后续添加古籍的接口

### 设计要点

1. **固定顶部**（不随滚动消失）
   - 卦名 + Unicode 符号（如 ䷀ 乾为天），大字加粗
   - 象课一行：`六龍御天之課 / 廣大包容之象`
   - history 一行（灰色小字）
   - 切换按钮行：DotButton 风格（与起卦/算卦 header 一致）

2. **QScrollArea 内容区**（垂直排列，自然滚动）
   - **卦辞/彖传/大象传 block** — 始终显示
   - **六爻 block** — 6 行，每行紧凑格式：`爻名  爻辞` + 换行缩进 `象曰: xxx`，始终显示
   - **可切换内容区** — QStackedWidget 根据按钮切换显示不同来源的解读

3. **切换机制**（可扩展古籍）
   - 按钮组：`[●倪师] [○古籍] [+]`
   - 默认选中倪师
   - 点击 [+] 弹出古籍名称输入 → 创建新按钮 → 对应 QStackedWidget 新页面
   - 古籍页面默认显示古籍原文（后续手动填充内容）

4. **卦图展示**
   - 倪师模式下：卦图 jpeg 作为缩略图显示在「图解」区域上方
   - 点击可放大查看（QDialog 弹窗显示原图）

5. **字号**
   - 复用全局 font_size 系统（12-24px）
   - 卦名字号 = font_size + 4（bold，与 header 标题一致）
   - 正文 = font_size
   - 标注/象曰 = font_size - 1（稍小）
   - 象课/history = font_size（普通字重）

6. **文字颜色**
   - 跟随 refresh_text_color() 链（深底白字/浅底黑字）
   - section 标题用 accent 色（#007aff）区分段落

### 与现有布局的集成

在 `src/tabs/yijing_viewer.py` 中，QiguaPanel 下方添加新 Widget：

```python
# yijing_viewer.py __init__
self._qigua_panel = QiguaPanel()
layout.addWidget(self._qigua_panel)

# 新增：卦象资料面板
from ..yijingTab.reference_panel import ReferencePanel
self._reference_panel = ReferencePanel()
layout.addWidget(self._reference_panel)  # 占据剩余空间
```

`ReferencePanel` 独立于 QiguaPanel，获取全部 tab 宽度，有自己的刷新链。

### 实现阶段

1. **Phase 1**：ReferencePanel 骨架 — 固定 header + QScrollArea + 刷新链
2. **Phase 2**：经典原文渲染 — 卦辞/彖传/大象传 + 六爻（始终显示）
3. **Phase 3**：倪师内容渲染 — 图解/卦解/阳宅/河洛
4. **Phase 4**：切换机制 — 倪师 ↔ 古籍 按钮 + QStackedWidget
5. **Phase 5**：古籍扩展接口 — [+] 按钮 + 自定义古籍页面
